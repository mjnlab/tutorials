# Tutorials

Companion code for the tutorials on the MJNLAB blog. Each folder belongs to one blog post and is named after it.

| Folder | Blog post |
| --- | --- |
| [`applied-ml-supervised-learning`](applied-ml-supervised-learning) | Applied ML: A Beginner's Guide to Supervised Learning |

## How to use

Every folder is its own self-contained project, managed with [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/mjnlab/tutorials.git
cd tutorials/<folder>
```

Then follow the README in that folder.
